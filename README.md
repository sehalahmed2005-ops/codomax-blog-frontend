# Inkwell – Blog Application (Frontend)

Codomax Digital Solutions – Full Stack Web Development Internship, Module 01.

Responsive blog UI built with HTML, CSS and vanilla JavaScript.

## Pages
Home, Register, Login, Dashboard, Create Blog (also edits posts).

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
Auth and posts are stored in `localStorage` for now. Module 02 replaces this with a Node.js + Express REST API.
